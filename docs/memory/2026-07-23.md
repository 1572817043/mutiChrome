## 当前边界

- operation 当前仍只保存在前端内存，不落盘。
- 没有真正的后端队列、跨窗口锁、强制解锁按钮。
- 120 秒超时只是防止底层命令永久卡死，不是完整调度器。
- V4.0 的窗口注册表目前只在平铺窗口流程中消费，暂未接入同步布局和独立窗口面板。
- 布局预设当前只有 `grid`；未做预设持久化、用户自定义布局、实时同步或键鼠同步。
- V4.0 实机只验证了两个已运行 Chrome profile 的平铺链路；多窗口、最小化、容量超限和权限失败仍主要由自动化测试覆盖。
- Claude CLI 最终复审长 prompt 无输出，短 prompt 也未给实质审查；本轮采用前一次有效红队意见并已修 P0。
