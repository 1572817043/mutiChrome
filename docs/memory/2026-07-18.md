## 后续注意

- 完整备份当前是整目录复制，不做增量、压缩、加密或云同步。
- 大 profile 目录可能占用较多磁盘空间，后续可考虑备份前提示可用空间或做压缩包导出。
- 批量删除文件夹不是事务型操作；如果中途失败，已经删除成功的文件夹不会自动还原，但账号索引会保留，后续可用健康检查发现缺失目录。
- 窗口管理 V1 仍是进程级/手动窗口能力：运行状态只判断 profile 进程是否存在，“切换到账号”只把对应 Chrome 主进程拉到前台，“检查窗口”能汇总窗口数量、首窗位置/尺寸和首窗最小化状态，“平铺窗口”只移动选中运行且有可读窗口账号的首个窗口，并尊重屏幕可用区域偏移；窗口过多时会提示分批处理；多窗口账号会提示仅平铺首个窗口；权限类失败会提示辅助功能设置位置，但仍不知道具体标签页，也不是同步控制。
